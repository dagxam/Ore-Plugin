В нижней части мира (у бедрока) генерируются одиночные блоки руд.
Блоки-руды нельзя сломать. Добыча идёт «ударами» при удержании ЛКМ по блоку.

За каждый «тик удержания» выдается дроп (с учётом Fortune), после 15–25 ударов руда превращается в бедрок.

Через заданное время (по умолчанию 1 час) узел руды автоматически возрождается на том же месте.

Генерация управляется: слои снизу, минимальная дистанция между рудами, целевое/максимальное число узлов на чанк, веса типов руд, «плотность».
Геймплей

Найти: руды появляются только внизу мира, строго касаясь бедрока, в первых N слоях от минимума мира (по умолчанию 7).
Добыть: удерживай ЛКМ, стоя нацелившись на руду — дроп приходит каждые X тиков удержания (настраивается).

Сломать нельзя: классические поломки, взрывы, поршни игнорируются/отменяются.

Исчерпание: после заданного количества «ударов» руда превращается в бедрок, а через конфигурируемую задержку возрождается тем же типом руды.
Ключевые возможности

Устойчивое хранение: данные узлов, обработанные чанки и очередь респаунов сохраняются в plugins/BedrockOres/nodes.yml.

Гибкая генерация:
layers-from-bottom — сколько нижних слоёв участвует
min-spacing — минимальная дистанция между узлами (4–5 по умолчанию)
target-per-chunk, max-per-chunk — целевое/максимальное количество узлов на чанк
chance-per-block + density-multiplier — регулируют «плотность»
ore-weights — веса появления конкретных руд
Производительность:
Дроп сразу в инвентарь, опыт напрямую — почти нет лишних сущностей
Удары при удержании идут «батчем», с лимитом на тик (чтобы не грузить тики)
Респавн руд происходит только в загруженных чанках, без принудительной загрузки
Команды админа: перезагрузка конфига, сброс флагов генерации, мгновенная перегенерация загруженных чанков.

Установка

Требования: Paper/Purpur 1.21.8+ (рекомендуется Paper/Purpur), Java 21.
Положи JAR в plugins/, запусти сервер один раз для генерации конфига.
Отредактируй plugins/BedrockOres/config.yml под свои миры и параметры.
Перезагружать сервер не обязательно — есть /bedrockores reload и /bedrockores restartgen.
Команды и права

Базовая команда: /bedrockores (алиасов нет)
Права: bedrockores.admin (по умолчанию op)
Список подкоманд:

/bedrockores help
Справка по командам.
/bedrockores reload

Перезагрузить config.yml и веса руд (ore-weights) на лету.
/bedrockores clearflags [мир|all]

Очистить флаги «обработанных чанков» для выбранных миров (генерация снова пойдёт при загрузке чанков).
/bedrockores regenloaded [мир|all]

Перегенерировать узлы в уже загруженных чанках (удаляет существующие узлы/очереди респаунов в них и генерирует заново).
/bedrockores restartgen [мир|all]
clearflags + regenloaded — полный «рестарт генерации» без перезагрузки сервера.

Примеры:

/bedrockores reload
/bedrockores clearflags all
/bedrockores regenloaded world
/bedrockores restartgen all
